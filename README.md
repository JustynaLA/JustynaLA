## How I work with data

- **Check before trusting:** I profile data for missing values, duplicates and inconsistencies before any analysis.
- **Reconcile against the source:** row counts, keys and values, not just totals.
- **Explain clearly:** every project ends with a plain-English finding and a recommendation.
